# My Knocker — хоррор-мод для Minecraft 1.20.1 (Forge)

Сталкер в духе The Knocker: следит за вами, замирает, когда на него смотрят, стучит в двери рядом с вашей
кроватью, приходит к спящему игроку, пугает скримером и может напасть. Весь код написан с нуля.
Персонаж — 3D-модель (GeckoLib), которую скрипт делает из вашего фото.

> ВАЖНО: пока в моделях стоит ЗАГЛУШКА (тёмная фигура). Ваше фото подставляется одной командой, см. ниже.

## Что нужно игрокам и серверу
* Minecraft 1.20.1 + Forge 47.x
* **GeckoLib 4.4.9** (положить рядом в папку `mods`)
* Мод нужен и на сервере, и у КАЖДОГО игрока (новая сущность: без мода на клиенте зайти нельзя).
  События создаются отдельно для каждого игрока на сервере.

## Как получить .jar
**Вариант А — без установки чего-либо (GitHub Actions):**
1. Создайте репозиторий на github.com, загрузите в него всё содержимое этой папки.
2. Вкладка *Actions* → *Build mod jar* → *Run workflow*. Через 3–5 минут скачайте артефакт `myknocker-jar`.

**Вариант Б — на своём компьютере (нужна Java 17):**
```
./gradlew build        (Windows: gradlew.bat build)
```
Готовый файл: `build/libs/myknocker-1.0.0.jar`.

## Как поставить ваше фото
1. Нужен PNG человека в полный рост, анфас, **с прозрачным фоном** (или любое фото + флаг `--remove-bg`).
2. `pip install pillow numpy` (для `--remove-bg` ещё `pip install rembg onnxruntime`)
3. `python tools/make_character.py my_photo.png`
4. Пересоберите мод (см. выше). Скрипт сам обновляет модель, текстуру, анимации, картинку скримера и хитбокс.

Полезные опции: `--height 3` (рост в блоках), `--depth 9` (толщина тела), `--head 0.45` (для фото по пояс/портрета),
`--rows 128` (больше деталей), `--tex-height 1024` (чётче лицо). Устройство модели: силуэт нарезается на тонкие
боксы, спереди на них натянуто ваше фото (лицо без искажений), в центре тела боксы толще, поэтому фигура объёмная.
Сзади — тёмная размытая зеркальная копия.

## Как менять персонажа самому
* **Текстура:** `src/main/resources/assets/myknocker/textures/entity/knocker.png` — верхняя половина = лицевая сторона,
  нижняя = задняя. Можно дорисовывать в любом редакторе, размер не менять.
* **Модель и анимации:** откройте `geo/knocker.geo.json` в Blockbench (File → Open Model). Для редактирования анимаций
  поставьте бесплатный плагин «GeckoLib Animation Utils». Кости: `root`, `body`, `head`.
* **Скример:** `textures/gui/jumpscare.png` (256×256), замените любой картинкой.
* **Звуки:** `assets/myknocker/sounds.json`. Сейчас используются ванильные звуки. Положите свои `.ogg` в
  `assets/myknocker/sounds/` и укажите `"name": "myknocker:ваш_файл"`.
* **Хитбокс:** `src/main/java/com/myknocker/KnockerSize.java`.

## Настройки (config/myknocker-common.toml)
Шансы, перезарядка, длительность погони, и по отдельности включение/выключение: преследование, стук, визит ко сну,
скример, атаки.

## Команды для проверки (нужны права оператора)
`/knocker stalk` · `/knocker knock` · `/knocker sleep` · `/knocker hunt` · `/knocker clear`
А ещё в творческом режиме есть яйцо призыва.

## Как ведёт себя Кнокер
* **Преследование:** появляется вдали (чаще за спиной), подкрадывается, пока вы не смотрите; замирает, когда смотрите;
  если подпустить близко и обернуться — скример; если долго смотреть издалека — исчезает.
* **Стук:** ночью, если вы рядом с кроватью/точкой возрождения («знает, где вы живёте»), стоит снаружи и стучит в
  ближайшую дверь. Если заметили в окне — скример.
* **Визит ко сну:** иногда встаёт у кровати спящего, при пробуждении — скример.
* **Атака:** после скримера (с шансом `attackChance`) или если его ударить — гонится и бьёт; потом исчезает.
* Не спавнится естественно, в мирном режиме отключён.

## Честно о границах
Сделано и проверено: фото → модель/текстура/UV (проверка совпадения с исходником 100%), JSON-файлы, синтаксис Java.
**Не проверено:** сборка и запуск в самом Minecraft — в среде, где это писалось, нет доступа к серверам Forge.
Поведение написано по открытому описанию Knocker, а не по коду оригинала, поэтому тайминги и звуки приблизительные.
